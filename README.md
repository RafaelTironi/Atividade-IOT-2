# Atividade-IOT-2

Discente: Rafael Tironi

Docente: Amanda Paul Dull

Esse repositório serve de exemplo para a entrega de atividades da matéria de IoT.

https://www.tinkercad.com/things/hKBfQqFTKjU-atividade-1aula4

Enunciado: Prática: Controle de Microservo com Potenciômetro 

Em projetos de IoT, é necessário integrar dispositivos de entrada e saída para realizar ações de controle. Nesta atividade, utilizando o Tinkercad, você deverá integrar um potenciômetro e um microservo ao Arduino, utilizando a leitura da entrada para controlar a posição do atuador.

Entrega da Atividade

Após concluir a montagem e a programação no Tinkercad, registre a atividade no seu portfólio do GitHub, seguindo o modelo de repositório presente no AVA. Para esta atividade, o repositório deverá apresentar:

Link do projeto no Tinkercad (público);

Imagem do circuito montado;

Código utilizado;

Breve descrição da atividade e do seu funcionamento.
